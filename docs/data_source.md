# Data source

This project uses the **Space Missions** dataset from Maven Analytics.

- Dataset period: 1957–2022
- Original source: Next Spaceflight
- CSV mirror used during development:
  https://github.com/vm8181/Space-Mission-Analysis/blob/main/space_missions.csv

The dataset includes:
- Company
- Location
- Date
- Time
- Rocket
- Mission
- RocketStatus
- Price
- MissionStatus

## Important limitation

The dataset ends in 2022, so the results are historical and should not be interpreted as a current market or safety ranking.
